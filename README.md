# EA1 - Manipulación de Vectores en Java

## Objetivo

Desarrollar un programa en Java para practicar la creación y manipulación de vectores, realizando operaciones de búsqueda, determinación del mayor y menor valor, identificación de múltiplos, cálculo de suma y promedio.

## Funcionalidades

1. Crear un vector de 15 números enteros.
2. Validar números entre 10 y 100.
3. Buscar un número dentro del vector.
4. Determinar el número mayor y menor.
5. Identificar los múltiplos de un número X.
6. Calcular la suma total de los valores.
7. Calcular el promedio.
8. Crear un nuevo vector con los números por encima del promedio.

## Tecnologías

- Java
- JDK Eclipse Temurin
- Visual Studio Code

## Resultado

El programa fue probado correctamente en consola.

Vector utilizado:

75 35 50 100 40 60 25 80 90 15 55 70 30 45 85

Resultados:

- Mayor: 100
- Menor: 15
- Suma: 855
- Promedio: 57
- Cantidad de números por encima del promedio: 7
